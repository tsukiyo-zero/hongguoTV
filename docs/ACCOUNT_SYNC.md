# 红果账号与同步

当前原生客户端支持红果官方扫码登录、账户收藏、账户观看历史、账户预约和相关作品入口。本机记录与账号记录分开保存；账号缓存按当前会话隔离，退出或切换账号后立即清空旧账号资料。

## 登录

- 已验证的路线为电视显示二维码，手机红果 App 扫码并确认。
- 手机号短信入口走 App passport 通道（`/passport/mobile/send_code/v1/` 与 `validate_code`，先用匿名设备注册取得装置身份再发码，验码与账号请求保持同一 device_id/iid）。2026-11-03 实测：网页端 `hongguoduanju.com` 发码已要求滑块验证（错误码 1105），App 通道发码正常返回打码号码、`retry_time` 与 `mobile_ticket`。
- 收到短信不代表已取得有效登录态：平台仍可能拒绝验证码会话（`error_code 1`，需重新发码），该通道的完整登录尚未实机验收；不应反复自动发送或提交验证码。
- 取得会话后必须通过红果账号资料验证，再保存登录态。
- 登录态用 Android Keystore AES-GCM 加密保存，独立于本机片单备份；不记录密码、验证码、Cookie 或令牌。
- 不以模拟器提取或导入凭据替代电视直接登录。

## 观看历史

- 「观看历史」包含「本机历史 / 账户历史」子页签，分别保留数据；账户历史读取当前账号最近 50 部记录。
- 本机续播采用本机进度，账户历史续播采用云端集数和时间。
- 云端续播优先匹配分集 ID；与官网分集列表不一致时，使用有效的云端集号映射到实际分集并保留时间。无法确认分集时不把云端时间套到第一集。
- 首页「观看全集」进入详情后，本机和当前账号已读取的云端记录按更新时间选择（同时间优先本机）；详情续播和对应选集按钮使用同一位置。仅使用当前账号最近已读取的 50 条历史，退出或切换账号后旧账号的详情续播信息失效。
- 云端历史不会批量导入本机；实际在电视播放才产生本机观看记录。
- 电视定期及暂停、退出时请求上传播放进度。不能把接口接受上传等同于手机端逐集、逐秒双向续播已完整验收。


## 收藏与子页签

「收藏」包含「本机收藏 / 账户收藏」，进入时记住上次来源；观看历史也独立记住来源。原本机收藏和观看记录无需迁移，不自动导入或上传。

账户收藏使用 `/reading/bookapi/bookshelf/video/info/v1/`，解析 `data.video_shelf_info`；参考公开协议 [HGTV Account.kt](https://github.com/charlie901208/HGTV/blob/feat/phone-login/android/core/src/main/kotlin/com/hgtv/star/core/Account.kt)。账户收藏读取只验证了请求及样例解析，尚待用户以实际账号核对。接口返回批次的分页契约尚未验证，不宣称覆盖账号全部收藏。

长按菜单和详情页分别提供本机收藏、账户收藏操作。账户增删使用 `/reading/bookapi/bookshelf/video/update/v1/`，`book_type=2`，操作码 0 加入、1 取消；不调用小说书架 add 接口。协议参考 HGTV 公开 videoShelf 实现，平台实际接受情况仍需手机核对。

账户操作先确认目标账号，随后读最新列表，确有必要时才发一次写请求，再回读列表；添加需看到目标作品，取消需目标从本次读取的列表消失。成功文案描述回读结果，不将 code=0 单独视为成功。回读失败或列表未变化时提示未确认，需用户主动刷新后才允许再次提交；禁止网络层自动重试写请求。不自动搬运本机收藏。确认框在账号切换后失效。

列表分页契约未验证，取消后的缺席只能说明本次读取列表未包含目标；必要时仍需手机核对。新写接口经过请求模型和模拟回读测试，尚待用户账号实机验收。

读取失败保留同一账号上次成功数据并提示错误；退出或切换账号立即清空。请求和结果均校验会话代次，旧账号迟到结果不能覆盖新账号。账户数据不写入本机片单或导出备份。

顶部依次为首页、搜索、排行榜、收藏、观看历史、账户预约、设置。预约与设置的内部位置已前移；账户历史续播和待上线禁止播放仍需回归。

## 预约

账户预约分别读取已上线、待上线，每类目前读取最近 20 部。待上线使用平铺字段，与已上线的嵌套剧集资料不同，不能套用同一种解析。用户已核对已上线 9 部、待上线 11 部均显示正常。

详情页相关作品可打开其他季，待上线提供预约入口。提交请求被接受和账户列表确认是不同状态；只有列表确认后才显示已预约。相关协议与手动验收见 [相关作品说明](../kotlin-tv/RELATED_WORKS.md)。

## 排查注意

扫码成功但电视仍未登录曾由 Android 的异步 OnDismiss 回调造成：保存任务受 busy 状态阻挡而被跳过。主动结束二维码操作时须先解除关闭监听、同步结束当前操作，再启动保存任务；延迟的关闭回调不能取消后继任务。

账户接口、登录态加密及异步会话隔离的更多要点见 [开发排查笔记](DEVELOPMENT_NOTES.md)。旧版本调试流水已清理，必要时通过 Git 历史追溯。

## 集数与进度标签

收藏及账户预约卡片以两行展示总集数与续播集号。本机收藏采用本机 checkpoint 和收藏更新检测的总集数；账户收藏、已上线预约采用当前账号最近 50 部历史，不回退到本机进度。checkpoint 表示“看到第 N 集”，不能推断前面每集都已观看。没有账号记录时显示最近 50 条中未发现记录，不声称从未观看。未知总集数显示待更新；待上线显示暂不可观看。已上线预约缺少总集数时，使用既有 multi-detail 只读接口批量补充 drama_chapter_number；补充失败仍保留有效预约列表。
