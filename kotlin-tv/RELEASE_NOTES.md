果映 TV 0.1.35 更新说明

- 播放错误按解码模式区分文案，诊断行标注构建类型
- 播放面板切换解码后延后重建，并提示设置页下次生效
- 强制硬解不再自动退化软解，并在错误页给出改解码方式入口
- 放宽回退时同步放宽 track 复核，修复强制硬解下无法播放
- bytevc2 判为不可解，并在严格档位全失败后宽松重试
- 解码状态行同时显示 HEVC 与 H.264 的硬解数量
- 强制硬解把所有档位排除时回退到放宽判定
- 强制硬解时跳过无硬件解码器的编码，回落到 H.264
- 解码状态行补上本机 HEVC 解码器候选数量
- 播放面板的解码方式改为弹出选择并重建播放器
- 全局设置页也可切换解码方式
- 播放设置显示当前实际解码器与硬/软解判定
- 播放设置支持切换解码方式（自动 / 强制硬解 / 强制软解）
- 更新回退链单源超时降到 8 秒，全源失败才提示
- 更新检查支持 GitHub 国内镜像，摆脱对 GitCode API 的依赖
- 更新检查在 GitCode 限流时回退到 GitHub 发行版

支持 Android 6.0 及以上；保持新包名与原签名，同包名旧版可覆盖更新并保留数据。
