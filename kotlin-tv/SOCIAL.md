# TV 评论与弹幕调试

评论与弹幕已随 TV 0.1.3（versionCode 44）正式发布。后续调试保持版本号不变，不生成或替换线上正式更新清单。

正式播放页按 ↑ 打开“更多”，进入“评论”或“弹幕设置”。评论面板支持上下方向键浏览、到底继续加载、手动加载更多和失败重试，返回键关闭面板；播放继续。普通评论匿名读取 App 接口，整剧剧评标明官网节选。点赞数量只读，没有发送或回复按钮。

弹幕使用真实毫秒时间轴，在原生 Canvas 上逐帧绘制。轨道调度不再因「轨道已满」丢弃弹幕：轨道占满时按最小间隔顺延显示（上限 3 秒），五秒内相同文本合并为「文字 ×N」并保留最早时间，重叠批次按真实 ID 去重；不再按缓存总量隔条隐藏。高密度超过轨道容量时允许重叠，避免无限排队到片尾之后。时间段按服务端 nextMS 连续补齐，不假定每段固定为三十秒。实际流畅度与指定剧集数量仍待实机对照。

默认按屏幕高度自动计算行数（约 6–10 行）、24dp、标准速度、85% 透明度、上部区域。播放中可调开关、字号、行数（自动 / 4–12）、透明度（60–100%）、显示区域（上 / 中 / 下 / 全屏）、速度与相同弹幕合并；配置保存在本机。暂停时冻结，拖动后按目标时间段读取，切集、后台和退出清理旧请求与内容。入口位于正式播放页，首页首集试播暂未接入。

评论、时间轴弹幕、签名及有界响应读取位于 core，Mac 后端通过别名复用，TV 不运行 Java 回环服务。读取不使用账号 cookie，不涉及账号写操作。

自动检查：`:core:test :app:testDebugUnitTest :app:assembleDebug :app:lintDebug`。Robolectric 在 API 23 与 API 26 验证评论加载、去重、焦点恢复、设置保存和签名。实际 TV 遥控器布局、弹幕流畅度、暂停/拖动/倍速及自动下一集由用户手动验收；不自动安装或操作模拟器。

详情页也提供本集评论入口。常见表情标签使用随包分发的通用表情图片，避免 Android 6 字库缺失；未识别的标签保留原文。正文增加行距，详情页与播放页共用评论面板。

详情页移除重复选集按钮，主操作仅播放与本集评论，收藏和简介为次级操作。评论按整条卡片聚焦，元信息与正文分层；追加保持阅读位置，关闭全文和面板恢复原焦点。

首页效率调试：播放器优先消耗已有开头缓存，不为凑满网络分块而阻塞首读；后续作品预加载等待当前视频至少 3 秒缓冲。日志只记录推荐请求、播放地址和媒体索引耗时，不含账号或完整媒体地址。实际首帧耗时仍需电视端对比。

设置精简：移除手机备份恢复、恢复隐藏推荐及空的数据管理分组。保留账号登录、云端继续观看、刷新账号记录、退出及同步状态，不清除已有本机数据。

弹幕请求上下文补充修复：时间轴读取复用现有匿名注册会话，使用一致的 7.4.3.32 查询、UA 与签名上下文，并将实际 POST 正文纳入签名；跨时间段携带服务端续读游标。不使用账号 Cookie，不因结果稀疏循环注册或自动换身份，注册失败保留正常失败重试。普通评论列表沿用原请求流程。针对《天幕直播：古人每周来我家》148 集版第 46 集，旧请求首段仅返回 1 条；修改后的实际读取三段返回 9/13/9 条，共 31 个不同 ID，包含截图中缺失的皇亲、妙云和真好看相关内容。数量为该次匿名样本，不代表服务端固定总数或与官方展示完全一致，画面仍待用户验收。

弹幕排查：播放中打开“弹幕设置 → 查看读取诊断”，D3 标记用于确认该测试构建，显示最近区间的接口条数/有效条数、缓存去重条数、合并排程条数、当前时间范围内条数及画布尺寸，不显示身份、Cookie、签名、游标或评论正文。“重新读取弹幕”会清除短期读取缓存后重新请求。设置面板支持滚动。指定集接口样本不等同于用户设备显示已修复；用户反馈仍只见一条，需依据设备诊断继续定位，尚未通过实际画面验收。

弹幕设置布局优化：首屏提供开关、字号、密度（少/标准自动/多）显示区域和重复合并；“更多设置”折叠收纳精确行数、不透明度与速度，“弹幕排查”折叠收纳重新读取及 D3 诊断。密度对应 4 行/自动/12 行，原有自定义行数保留并明确显示；密度和精确行数文案即时同步。调整即时生效并保持焦点，开关保留已有读取缓存；重新读取清除缓存但保持面板打开。面板支持滚动，不改变接口、签名或分页逻辑，弹幕数量稳定性继续观察。
