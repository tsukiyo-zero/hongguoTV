# Mac 试验客户端

TV 为主要维护目标。已验证的 Mac 版本通过 PR 合入 `main`；后续在长期分支 `feature-mac-client` 开发，合并后保留该分支。Mac 版本与 Android 版本独立。

## 安装和功能

解压 `outputs/mac/release-0.3.1/hongguoMac-arm64-0.3.1.zip`，打开 hongguoMac.app 或拖入「应用程序」。支持 Apple Silicon（arm64）、macOS 13+，自带 Java 17，不需另装运行环境。使用本机临时签名，未经 Apple 公证；当前用于本机试验。

左侧固定导航可切换功能；片单使用自适应多列卡片铺满内容区，打开作品后再显示独立播放页，工具栏右上角可搜索。

- 搜索：全部剧集搜索、分页。
- 找剧、榜单：真人剧、漫剧、AI 剧，题材筛选；榜单使用 TV 同款热播榜数据。
- 推荐：官方综合、漫剧和真人剧推荐，换一批、加载更多。点击作品会试播首集，可点上一部、下一部、观看全集。推荐试播不写本机历史、不上传账号进度；点观看全集或选集后才进入正式观看。支持下一部首集预加载，切换可能短暂停顿；未验证账号个性化效果。
- 收藏、历史：Mac 本机片单；支持右键管理。记录每 5 秒及切集、关闭时保存，继续播放按分集 ID 匹配。支持自动下一集、0.5～2 倍速、480/720/1080P 上限，切清晰度保留播放位置和暂停状态，实际清晰度取决于源提供的兼容资源。
- 账户：红果官方扫码登录；侧栏独立提供账户收藏、账户历史、预约（已上线/待上线）。登录确认、会话恢复和进入账户页都会触发读取，区分正在加载、失败重试及无记录。账户历史最多读取50条，预约每类最近20条；右键可操作账户收藏，相关作品的待上线项目可预约。
- 评论：普通播放、首页试播和全屏均可打开本集评论与整剧剧评，查看头像、作者、日期和只读赞数；支持对已加载内容筛选、排序、复制和打开官方页面。本集评论使用 App 评论接口的真实游标，下滑到底部自动继续加载，也可手动点击加载更多，跨批去重、失败保留已加载内容并可重试；筛选或改变本机排序后使用按钮继续加载。整剧剧评仍为官网公开节选。读取不携带账号凭据，发送和回复尚未接入。
- 弹幕：匿名读取官方时间轴弹幕，首页、普通播放与全屏均支持开关和失败重试。随暂停、拖动和倍速同步，按时间段加载与预取；过滤引导提示、无效状态和错集数据。显示密度最多四行，同一行不重叠。
- 更新：检查、下载、校验 Mac 更新包，最后由用户手动退出、解压、替换应用。

剧集详情包含总集数和相关作品，可查看其他季。Mac 原生播放器提供暂停、音量、时间拖动、全屏等控件。全屏播放时鼠标静止约 2.5 秒自动隐藏控制栏，移动鼠标或按键恢复，暂停时显示控制栏。关闭窗口会退出应用并停止辅助进程。

## 数据和账号

Mac 本机记录存于 `~/Library/Application Support/HongguoTVMac/library.json`，与 TV 数据分开。登录态只存于 macOS 钥匙串，不写入片单文件或仓库；辅助服务仅在内存中使用会话。退出账号清除钥匙串登录态与界面云端列表，保留本机收藏、历史。

正式观看时每隔至少30秒上传一次进度。失败时保留本机记录并显示状态。扫码获取二维码已做匿名联网检查，实际窗口已读取50条账户历史；账户收藏写入、跨设备续播等仍需本人在手机和 Mac 对照验证；不把扫码成功等同于所有云端能力验证通过。

## 构建与验证

需 JDK 17（含 jlink）、Gradle 8.14.3、Xcode Command Line Tools。独立 Gradle 工程直接复用 `kotlin-tv/core`，不会改 TV 构建配置、包名、版本或更新源。

```sh
JAVA_HOME=/你的/JDK17路径 \
HONGGUOTV_GRADLE=/你的/gradle路径 \
bash scripts/build-mac.sh

# 不联网的记录、清单、账户历史加载、全屏控制栏、评论和弹幕加载隔离回归测试
bash scripts/test-mac-local.sh

# 自愿执行的匿名联网测试：搜索、分类、榜单、相关、推荐、二维码生成、原生播放和拖动
python3 scripts/test-mac.py
```

`tests/ModelSmoke.swift` 还验证实际播放控制的进度持久化、暂停状态下切清晰度、倍速、自动下一集和试播记录隔离；使用临时记录，禁用账号恢复。未操作 TV 或 Android 模拟器。

## Mac 更新发布

构建自动产生 ZIP 和 **mac-update.json**，与电视的 update.json 区分。

Mac 固定读取同仓库 GitCode Release **mac-stable** 的 mac-update.json。首次发布时建立此标签/发行版，但**不要设为 Latest**；Latest 保留给 TV。后续在 mac-stable 上传新版本 ZIP、替换 mac-update.json，旧 ZIP 可保留。每次提高 Info.plist 的 CFBundleVersion，清单依据实际 bundle 元数据和 ZIP 哈希生成。

不要将 mac-update.json 改名为 update.json，也不要用 Mac 包替换电视附件。Mac 更新只允许 GitCode 及其官方文件 CDN 的 HTTPS 跳转，检查大小和 SHA256 后保存到下载目录，不自动执行或替换应用。

Mac 与 TV 版本号独立。例如 TV 0.1.2 与 Mac 0.3.0 可以同时存在；Mac 下一版递增 build（当前为 12），TV 仍按 Android versionCode 递增。Mac 的 mac-stable 标签保持不变，无需随每次更新新建标签。

## 实现与边界

- SwiftUI 窗口、AVPlayerView 原生播放器，避免当前系统 SwiftUI VideoPlayer 的初始化崩溃。
- 后端复用搜索、详情、账号、推荐和 MP4 解密；随机 127.0.0.1 端口及路径令牌，拒绝带 Origin 的跨站请求；账号写操作要求 POST。
- 视频按需在内存中解密，不持久化完整影片。网站接口及系统支持的媒体格式会影响可用性，样本验证不代表全部剧集均兼容。
- GPL-3.0-only；保留仓库历史和第三方声明，构建产物包含 LICENSE/NOTICE。分发时提供对应特性分支的实际源码提交。

## 0.3.0 Mac 刷剧与全屏

- 首页使用官方推荐数据，提供推荐、漫剧、真人剧频道；自动首集试播，上下键或按钮切作品，换批与末尾继续加载。账号会传给现有推荐接口，但不保证与官方手机端的排序一致。
- 下一部首集预取详情、媒体头和最多 1 MiB 的开头数据；缓存仅一个候选视频，进入播放时复用。仍使用单播放器，网络与解码切换可能有短暂停顿，不承诺无缝。
- 试播不写本机历史或上传正式观看进度，点击观看全集或选集后进入正式播放。
- 播放器可直接进入 macOS 系统全屏；移动鼠标显示剧名、集数、进度、图标式播放按钮、选集、清晰度、倍速和退出。打开选集时保持控件显示，关闭后恢复空闲隐藏。
- 我的整合账号、本机与云端片单、预约、自动下一集和更新入口。相关作品提供封面、季数与预约状态。
- 此版本尚未接入评论、回复和弹幕。

- 新增真实时间轴弹幕，按视频时间段读取，不使用普通评论代替。开关状态在本机保存，读取失败可重试。

- 可运行 `python3 scripts/test-mac-social.py` 验证包内服务的两个真实弹幕时间段与公开评论；不恢复账号或发布内容。

## 0.3.3 弹幕绘制改进测试版

- 弹幕从每 50ms 刷新位置改为目标 60 帧的动画时间线与 Canvas 绘制，网络预取单独每 250ms 检查。实际帧率取决于系统调度与机器负载。
- 排序与排轨仅在数据变化时计算；字体从 18pt 增至 22pt，改为白字实心黑描边，移除模糊阴影，整屏滚动时间从 7 秒延长至 10 秒。
- 保持真实播放时间同步、暂停冻结、拖动、倍速和切集隔离；普通评论仍等待有效的 App 连续加载游标，重复官网页面请求不会扩展为完整评论列表。

## 0.3.4 本集评论连续加载测试版

- 本集评论改用已验证的 App 评论列表，按服务端游标继续读取；下滑加载和按钮加载共用同一请求流程，跨批按真实评论 ID 去重。
- 初次读取失败可重新读取；后续失败保留当前评论并按原游标重试。拒绝不推进或重复的游标，切剧、切集隔离旧请求。
- 签名、真实评论来源、游标推进、重试及去重有本地回归；`scripts/test-mac-social.py` 匿名验证包内服务的两批评论有新 ID，并继续验证弹幕和官网节选。界面滚动行为待用户手动验收。
- 整剧剧评仍为官网节选，发送和回复未实现。

## 发布版本约定

正式发布才递增对外版本号；当前正式版 0.3.0，下一正式版为 0.3.1。此前标为 0.3.1～0.3.4 的本地包均为调试构建，不是正式发布。后续调试保留计划发布版本号，以递增 CFBundleVersion 区分（当前 build 12）。

本次调试改用单调时钟插值弹幕位置，并修复主窗口已全屏时的视频全屏入口；待人工验收后发布。

共享弹幕核心补充：时间轴读取现复用匿名注册会话及一致版本的完整请求签名，正文参与签名；TV 接入相邻时间段游标。Mac 的原有四参数调用保持兼容，但 Mac UI 本轮未改动、未重新构建或做画面验收，不将 TV 样本验证等同于 Mac 验收。
