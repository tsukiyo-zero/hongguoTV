# 果映 TV · hongguoTV

非官方红果短剧客户端，主要维护 Android TV 版，同时提供原生 Mac 客户端 hongguoMac。

Android TV 使用 `kotlin-tv/` 中的 Kotlin 原生客户端，支持 **Android 6.0 及以上**。安装一个 APK 即可使用，无需部署 Node 或 Docker。Mac 客户端独立构建、独立更新。

## Android TV 下载、安装与更新

[GitHub TV 0.1.29 下载](https://github.com/tsukiyo-zero/hongguoTV/releases/tag/kotlin-v0.1.29) · [GitCode 发布记录](https://gitcode.com/tsukiyo-zero/hongguoTV/releases)

正式 TV 安装包通过 GitHub 和 GitCode 双平台发布；**应用内更新读取 GitCode**。首次安装从正式 Release 下载 APK，在电视上确认安装。后续同包名版本可在「设置 → 版本与更新」检查、下载并校验更新包，最后交给 Android 系统确认安装；无需每次手动到 GitHub 下载，也不支持静默安装。 Android 6/7 会依次尝试标准安装入口与 APK 查看入口，无法打开时尝试系统安全设置；厂商 ROM 兼容性仍需实机确认。若旧版更新入口无法打开，可从正式 Release 下载同包名、同签名 APK 手动覆盖一次，保留本机数据。

### 旧红果 TV 与新果映 TV

果映 TV 使用新安装标识 `io.github.tsukiyo_zero.guoyingtv`，与旧原生版 `com.hongguotv.nativeapp` 独立，可同时安装。**首次迁移到新包名需单独下载安装，不能通过旧 App 的覆盖更新完成**。当前正式版使用新包名；本地调试包不进入在线更新渠道。

本机数据和登录态不会自动迁移，平台账号需重新登录。底层保留了片单备份/恢复实现，但当前设置页没有接入入口，不能把它作为现成的用户迁移步骤；迁移入口需后续补齐并验证。以后果映 TV 的同包名版本继续使用原签名覆盖更新，保留其本机数据。

仓库名仍为 hongguoTV，Mac 客户端名仍为 hongguoMac。果映 TV 关于页注明项目、作者和非官方身份；图标与横幅来源见 [品牌资源](kotlin-tv/artwork/README.md)。

## TV 功能

### 找剧与发现

- 首页默认读取官方推荐流，也可切换漫剧、真人剧，试播作品第一集；上下换剧、换一批、观看全集或加入账户收藏。切回本次已浏览的来源时恢复列表和选中作品。
- 首页「观看全集」进入详情后，可按本机或当前账号已读取的较新记录续播；账户历史读取失败时保留已加载记录，空响应提示具体请求阶段；账户历史入口采用该条云端记录，本机历史入口仍采用本机记录。云端分集 ID 与详情不一致时，使用有效云端集号定位，不预先导入本机历史。
- 首页快速连续切换时，未缓存作品停留 300 毫秒后才准备试播，缓存命中仍直接接续。首页使用按登录身份隔离的短期首屏缓存，预加载相邻作品，换剧时接续已完成或仍在进行的预加载；播放模型和视频索引按需读取，减少串行等待。首次冷缓存仍需联网，实际速度受网络、接口和设备解码性能影响。
- 首页支持保存续刷分页和最近的去重记录，减少退出重进总从同一作品开始；默认推荐补齐注册会话和完整签名，首屏启用单列续刷时按官方协议切换续页接口，并保存服务端游标；耗尽后重新获取也保留最近去重记录，不将旧批次直接循环播放；推荐、漫剧、真人剧各自保存，试播不写入正式观看历史。
- 找剧支持全部、真人剧、漫剧、AI 剧；按服务端返回的主题、设定、背景、推荐排序、受众、上新时间等分组组合筛选，漫剧还可返回作品状态。每组左右选择、组间上下移动，支持重置与收起筛选；进入海报列表保持展开状态，详情返回保留选中条件与位置。找剧分类页自动续页，返回键回顶并聚焦「找剧」，加载失败时提供重试。
- 关键词搜索覆盖全部剧集，提供遥控器三栏搜索：左侧 A–Z/0–9 键盘、删除/清空及中文/手机输入，中间联想词与最近历史，右侧剧集结果；方向键选字、确定输入。找剧组合筛选继续独立保留，可从「屏幕键盘」进入搜索、按返回回到筛选。
- 输入剧名、关键词或拼音时，停顿片刻显示服务端联想词；选中候选后搜索。联想失败仍可直接搜索，匹配范围取决于服务端，并非离线拼音检索。
- 综合、真人剧、漫剧、AI 剧热播榜，以及榜内题材筛选。榜单采用六列海报网格向下连续浏览，卡片显示原榜名次及可用热度，筛选后保留原榜名次。
- 搜索与分类结果接近底部时自动加载下一页，追加保留当前选中位置；搜索遇到临时网络或服务错误时自动重试一次，仍失败则显示错误类型并保留列表，支持手动重试与回到顶部。
- 剧集详情提供简介、选集列表、集数分组和跳转集数；相关作品支持前后季浏览、跳转及下一季预约。

### 追剧与账号

- 本机收藏、观看历史、断点续播及整剧已看标记；本机收藏可检查新增集数，长按作品管理记录。当前首页是首集试播流，续看和片单管理通过收藏、观看历史进入。
- 红果扫码登录，支持账户收藏读取与增删、账户观看历史及云端续播；收藏与历史均按本机／账户分设子页签。
- 账户预约区分已上线、待上线，并显示上线提示。

本机记录与账户云端记录分开保存。退出或切换账号会清除旧账号的云端列表，不删除本机历史。旧「稍后看」及备份恢复底层数据结构仍保留，但当前界面不提供对应入口，不将其列为可直接使用的功能。账号能力及同步边界见 [账号同步说明](docs/ACCOUNT_SYNC.md)。

### 播放与遥控器

- 遥控器方向键选剧、选集、快进快退，确认键播放／暂停；播放页按 ↓ 选集、↑ 打开更多，返回键先收起控制层，再退出播放。
- 清晰度、倍速、画面模式与自动连播可调整并记忆偏好。
- 定时停止支持按分钟、本集播完或再播完指定集数停止，保存观看位置。
- 播放失败默认最多快速恢复三次，首次准备与快速恢复共享 20 秒网络准备额度；更长的慢段恢复需要主动选择“继续等待恢复”。恢复期间保留原因、阶段和操作，直到真正输出首帧才清除；可取消恢复或返回选集。错误页保留脱敏诊断与观看位置。
- 首页与正式播放共用经平台注册的匿名播放设备身份，避免使用未注册的随机 ID；无需账号登录，注册失败会单独提示，成功后在本次应用进程内复用。
- 播放模型读取按当前匿名会话的路径健康度选择，近期成功路径优先；空响应路径冷却 30 秒。前台最多四次不同候选请求，注册和模型请求共享 8 秒预算；已知路径全部失效时，可在本轮剩余额度内恢复一次匿名身份。注册恢复失败后冷却 5 秒，替代身份仍失败时冷却 30 秒，后续前台请求可重新尝试，不需退出首页；取消的任务不消耗恢复额度。后台只轻量读取一次、不主动轮换身份。正式播放仍可顺带缓存后两集模型，减少重复获取；不保证服务端持续异常时仍能播放。
- 正式播放切到正在准备的下一集时接续原任务，避免取消后重复请求；下一集沿用当前播放会话，索引准备好即可入队，由播放器继续缓冲，不等待固定 2 MiB 下载。
- 首页试播与正式播放使用完整的播放请求签名（含 Cookie 与请求体摘要），修复播放信息接口持续返回空响应的问题；服务端偶发空响应由有界换路与身份轮换尝试恢复，仍可能耗尽预算而失败。保留原清晰度选择和自动恢复。
- 按电视解码能力自动选流：超出盒子上限的清晰度（如竖屏高清）自动降档到可解的最高档位播放；盒子虚报能力导致播放失败时自动学习并降档重试，无需手动切换。
- 播放中监测音画偏移并自动重同步，缓解随播放时长累积（倍速下更快）的音画不同步。
- 部分剧集仅有 bytevc2（VVC/H.266）编码、电视无法硬解：应用可自动借用同一局域网内你自己的电脑（果映伴机）完成转码，电视按普通 H.264 播放。提供 macOS（dmg）与 Windows（msi）安装包（[伴机包固定下载地址](https://github.com/WingkySky/hongguoTV/releases/tag/relay-stable)），内置 ffmpeg 与运行时、开箱即用；也可用 fat jar 开发启动，支持自动发现/扫码填地址与令牌鉴权，详见 [relay/README.md](relay/README.md)。
- 应用内检查、下载及校验更新；同包名与原签名支持覆盖安装，新旧包名之间需单独安装。

### 评论与弹幕

- 详情页和正式播放页均可打开本集评论，支持连续加载、游标续读、去重、手动加载更多与失败重试。
- 常见表情使用随包图片显示，改善旧电视字库兼容；评论追加保留阅读位置，关闭面板恢复遥控焦点。
- 真实视频时间轴弹幕，暂停时冻结、快进快退后重新定位；支持开关、字号、速度、密度及本机设置记忆。

本集评论可连续读取，整剧剧评仍为官网公开节选。评论和弹幕均只读，未提供发送、回复或点赞操作；首页首集试播暂未接入评论与弹幕。实现与验收边界见 [评论与弹幕说明](kotlin-tv/SOCIAL.md)。

## Mac 客户端 hongguoMac

支持 **Apple Silicon（M 系列芯片）、macOS 13 及以上**。解压 ZIP，将 `hongguoMac.app` 拖入「应用程序」即可使用，自带运行环境，无需另外安装 Java。

[Mac 固定发布入口](https://gitcode.com/tsukiyo-zero/hongguoTV/releases/mac-stable) · [Mac 构建、更新与使用说明](desktop-mac/README.md)

- 首页推荐、漫剧和真人剧试播，支持切换作品、换批与下一部首集预加载。
- 搜索、分类找剧、排行榜、相关作品与前后季浏览。
- 红果扫码登录、账户收藏、观看历史、预约和正式观看进度同步；另有本机收藏与历史。
- 全屏播放、选集、清晰度、倍速、自动下一集及断点续播；全屏控制栏空闲后隐藏。
- 上下方向键切换试播作品，空格播放或暂停，左右方向键快退或快进 10 秒。
- 本集评论支持下滑连续加载与手动加载更多；整剧剧评提供官网公开节选。支持筛选、排序、复制及打开官方页面。

Mac 登录态保存在本机钥匙串，不随安装包分发。当前使用临时签名，尚未经过 Apple 公证；整剧剧评为官网节选，发送和回复尚未接入。另支持按视频时间同步的真实弹幕，可关闭及失败重试。

### Mac 更新与开发

Mac 与 TV **分别管理版本号和更新清单**。Mac 固定读取 GitCode 同仓库 `mac-stable` Release 中的 `mac-update.json`；每次发布上传新 ZIP 并替换该清单，保持标签不变，**不要将 Mac Release 设为 Latest／最新版**，最新版保留给 TV。Mac 目前下载并校验更新包后，需要手动解压替换应用。

已验证的 Mac 版本纳入 `main`。后续 Mac 开发继续在长期分支 **`feature-mac-client`** 进行，测试通过后按需通过 PR 合并到 `main`，不随每个 Mac 功能另开分支。TV 仍是主要维护版本，Mac 源码位于 `desktop-mac/`。

### 启动与播放界面体验（当前开发分支）

- 设置 → 外观与操作：可直接选择首页、找剧、排行榜、收藏、观看历史、账户预约、设置七个页签作为启动页面；默认仍进入首页，不提供“记住上次”。
- 可关闭首页自动试播；关闭后切换作品会准备首集并保持暂停，点击“继续试播”才开始，正式播放不受影响。
- 正式播放按 ↑ 或菜单键直接打开操作菜单，不暂停播放，↓ 仍为选集，确定仍为暂停／播放。自动连播进入下一集时不自动显示标题和进度菜单，可照常用遥控器唤出。
- 播放控制栏采用两排按钮（播放／上下集，选集／评论／弹幕／设置），减少横向键程；正常播放时信息层约 4.5 秒、操作栏约 8 秒无操作后收起。暂停、错误提示和弹窗操作不强制隐藏；返回键仍可主动收起。
- 播放时钟支持关闭、操作时显示、始终显示，默认操作时显示；使用电视系统时间。
- 开发调试包不改变正式版本号，新增界面仍需电视实机验收。

- 通用列表选择弹窗采用深色圆角面板与独立选项行；启动页、时钟、倍速、清晰度和画面模式显示当前项勾选并默认定位，暖橙底色和左侧指示条表示遥控焦点。确定立即选择，返回取消；长列表可滚动。确认、登录和输入类弹窗保留原有交互，并统一深色面板。

- 设置页采用左侧“播放／外观与操作／账户／应用与更新”分类、右侧选项布局。左侧聚焦即切换内容，右键或确定进入选项，左键返回分类；返回键先回分类，再回顶部导航。分类与各分类的选项焦点在本次应用会话内记忆。自动连播、首页自动试播可在设置行直接切换，其他选项沿用选择面板。

- 设置页采用代码绘制的深蓝渐变背景、轻薄半透明卡片、名称与当前值左右对齐，以及暖橙焦点指示条；行内开关采用统一胶囊样式。选择面板沿用同一视觉语言，无实时模糊或背景大图；全站浏览页面、通用弹窗及播放面板共用配色；视频画面继续使用纯黑底。

- 设置页视觉细化：导航以暖橙下划线标记当前页，遥控焦点用浅橙框区分；四个分类均保留底面，卡片高度随内容收拢，标题保留细分隔线，选项以留白区分。选项焦点采用左亮右隐的三段暖橙渐变和渐隐描边，聚焦名称为纯白、当前值为浅橙；分类保留低透明深蓝底面，实际焦点使用暖橙渐变与浅橙细框，焦点移入右侧后保留淡橙当前分类标记。背景加入轻微平铺纹理；进入设置默认聚焦当前分类的选项，按左返回分类、第一行按上返回导航。

- 首页、找剧、排行榜、收藏、观看历史、账户预约、设置及详情统一深蓝渐变背景、暖橙导航与焦点、轻薄卡片；筛选、系列作品、搜索、评论、登录与更新弹窗以及播放选集沿用同一视觉语言。二维码保留黑白高对比度，播放器保留黑色视频底与原有控制逻辑。

- 视觉可读性：操作与选择弹窗使用接近不透明的深色底，避免海报干扰菜单文字；通用按钮使用浅暖橙细焦点框。作品预览未聚焦时显示选择提示，详情简介保留全宽两行摘要并增加行距。

- 设置选项聚焦采用暖橙色渐变；开关随整行聚焦显示浅橙细描边，仍保持整行一个遥控焦点。

- 切换账户内容页时不再弹出连接中提示，保留页面状态与失败反馈；首页试播区域使用黑底和聚焦描边，找剧筛选增加横向及行间留白。

- 找剧长筛选行保留一屏常用项及当前选项，右侧固定“全部 · N 项”入口；打开四列选项面板后可用方向键选择，确认应用，返回取消。短筛选行直接展示。

- 播放恢复修复（开发分支）：连续空响应触发匿名身份更新后，先重新尝试首选播放信息接口，再回退备用接口；首选接口成功后重置连续失败计数。保持原有恢复预算，尚待电视验证。

- 启动页设为观看历史或收藏时，本机内容直接读取本地记录，不再误入空关键词搜索请求；账户内容仍沿用账户刷新流程。

## 完整相关季与跨季连播（开发分支）

相关作品不再按 30 项截断，保留接口返回的有效项目，当前系列优先并按季序排列，其他同 IP 系列按剧名主体分组后排列；“全部季 / 相关作品”提供四列网格，支持滚动选择和待上线预约。入口数量不含当前季，不承诺接口未返回的季。

设置 → 播放新增“跨季自动连播”，默认关闭，需同时开启自动连播。最后一集播放进度过半后，读取并提示可靠匹配的下一季，在画面底部显示不抢焦点的单行提示；按 ↑ 打开操作菜单可取消本次跨季连播。播完后直接从下一季第 1 集开始，不弹窗或倒计时。离开前台、切集或睡眠停止会取消。无法可靠匹配、待上线或读取失败时停在结束页，不跳过缺失季、不按相关卡片顺序猜测下一季。尚待电视实机验收。

季号兼容“第39季 / 40季 / 第四十季”等尾缀写法，统一用于同系列排序与连续季匹配；仍要求剧名主体一致、季号连续且下一季唯一，不做任意相似剧名合并。

### 更新包签名兼容性修复（开发分支）

内置更新同时请求旧版证书收集标志与 Android 9+ 签名信息，兼容 Android 9/10 及部分电视系统解析 APK 文件时缺少签名字段的情况。优先比较当前签名，必要时读取旧签名字段；无法读取证书或签名不同仍阻止安装，并分别提示原因。包名、版本、最低系统版本及文件大小/SHA256 校验继续保留，尚待受影响电视实机验收。

已经受旧版校验影响的设备，需要从本仓库官方 Release 手动下载并覆盖安装包含修复的版本一次；无需卸载，保持同包名和原签名可保留本机数据。旧版不会因服务器更新而自动获得此修复。

### 播放首次准备与恢复优化（开发分支）

同一注册会话复用签名器，保持进程 nonce 与启动时间稳定，每次请求仍更新时间戳并重新签名；首页与正式播放共享这份上下文。此前逐请求新建签名器与字段的进程语义不一致，已修正，但不据此断言所有空响应都由此引起。

首页进入全集时，可一次性交接 15 秒内刚取得的同集模型，避免同一资源重新请求；仅内存最多六条，手动重试仍重新获取。根据会话内近期成功和空响应记录选择首次路径，不再固定从头循环。前台主模型读取最多四次、共享 8 秒总额度；后台只尝试一次、模型阶段最多 2 秒，失败不消耗前台连续失败额度。恢复仍有次数上限，不反复随机生成未注册身份。

首页保留“前一部＋后三部”的准备结果，先准备下一部，当前播放稳定 3 秒、6 秒后再逐步扩展至后两部。首页当前作品遇到空响应仍可自动恢复两次，等待 2 秒、5 秒；初次准备与恢复共用 15 秒网络额度，避免重复叠加长等待。换剧、切分类、换批、离开或手动重试均取消旧任务；关闭自动试播后仍保持暂停。

正式播放的初次准备与默认快速恢复共用 20 秒网络额度，快速恢复最多三次；更长等待由用户主动选择。加载与恢复阶段持续可见，失败原因保留到真正出首帧，重试不会先隐藏整个状态层；可取消恢复或返回选集。同一播放实例自动恢复时尽量保留现有画面，首次播放无旧帧时显示准备状态。上述秒数限制的是网络准备，不保证在相同时间内完成解码和出画面。电视效果尚待实机验收，详情见 [播放稳定性说明](kotlin-tv/PLAYBACK_STABILITY.md)。

### Android 6 电视更新安装兼容

更新安装优先使用内容 URI 授权，依次尝试标准入口与常见安装器组件。Android 6 另将已校验的 APK 复制到应用专属外部 Download 目录，再校验大小及 SHA256，作为旧式文件入口兜底；外部目录不可用时仍尝试内容入口，不新增存储权限或放宽私有目录权限。Android 7+ 不外发文件 URI。安装仍须系统确认，无法绕过未知来源限制。全部入口失败时提示尝试数量和失败类别，日志不含安装地址或异常正文。小米电视 4A L60M5-4A（Android 6）尚待实机验收；旧版需先手动覆盖安装一次修复包。

### 手机号登录区号与验证范围

手机号登录采用用户提供的官方界面截图可确认的 14 个区号：大陆、香港、澳门、台湾、马来西亚、新加坡、印度尼西亚、缅甸、菲律宾、越南、柬埔寨、日本、韩国、阿联酋。Android APK 默认项及一次匿名设置响应中的三项不作为所有官方入口的通用限制。可选区号不代表短信已验证送达；非大陆短信均未完成实号验收。大陆与港澳保留有依据的位数校验，其他地区仅检查字符与国际号码总长度，不猜测各地前导零规则。支持完整国际号码粘贴，平台受理提示不等于实际送达，更换号码/区号后须重新获取验证码。

已完成官方 APK 静态核对及本地模拟回归；另在持有人授权下仅作一次实际发码请求，平台仍返回错误码7，未报告受理成功。已修正与 App SDK 不一致的 GET 明文发码，改用编码后的 POST 表单，关闭自动重试和重定向，不切换需要滑块的网页。海外收码故障仍未解决，不据此承诺可用。详见 [手机号登录验证说明](kotlin-tv/PHONE_LOGIN.md)。

短信设备初始化候选修正：请求先复用正常匿名设备注册，公共表单、查询与签名使用相同的实际 device_id/iid；同一注册会话保持账号签名上下文，发码/验码保留注册及同域会话，不再将固定设备表视为真实 App 初始化。注册失败不回退固定身份发码。持有人追加授权后，本轮设备注册成功、仅实际发码一次，平台仍返回错误码7，随后停止，未作第二次或验码。这项候选修正仍未解决海外发码，不能承诺可用；下一步需要官方 Android App 的实际对照。

短信号码格式候选修正：已在模拟器确认官方安卓 App 实际提供 14 个区号（含 +886）。静态核对输入组件发现 App 提交的是连续的区号与号码；TV 发码、验码现移除展示分隔空格后再进行 XOR 编码，不再沿用网页的带空格格式。界面显示与大陆号码处理保持原有行为。本轮仅完成本地回归，尚不能确认错误码7已解决。
