# 果映 TV · hongguoTV

非官方红果短剧客户端，主要维护 Android TV 版，同时提供原生 Mac 客户端 hongguoMac 与 Windows 客户端。

Android TV 使用 `kotlin-tv/` 中的 Kotlin 原生客户端，支持 **Android 6.0 及以上**。安装一个 APK 即可使用，无需部署 Node 或 Docker。Mac 客户端独立构建、独立更新。

### 旧红果 TV 与新果映 TV

果映 TV 使用新安装标识 `io.github.tsukiyo_zero.guoyingtv`，与旧原生版 `com.hongguotv.nativeapp` 独立，可同时安装。**首次迁移到新包名需单独下载安装，不能通过旧 App 的覆盖更新完成**。新包名正式版尚未发布；当前提供的本地测试包不进入在线更新渠道。

本机数据和登录态不会自动迁移，平台账号需重新登录。底层保留了片单备份/恢复实现，但当前设置页没有接入入口，不能把它作为现成的用户迁移步骤；迁移入口需后续补齐并验证。以后果映 TV 的同包名版本继续使用原签名覆盖更新，保留其本机数据。

仓库名仍为 hongguoTV，Mac 客户端名仍为 hongguoMac。果映 TV 关于页注明项目、作者和非官方身份；图标与横幅来源见 [品牌资源](kotlin-tv/artwork/README.md)。

## TV 功能

### 找剧与发现

- 首页默认读取官方推荐流，也可切换漫剧、真人剧，试播作品第一集；上下换剧、换一批、观看全集或加入账户收藏。切回本次已浏览的来源时恢复列表和选中作品。
- 首页「观看全集」进入详情后，可按本机或当前账号已读取的较新记录续播；账户历史入口采用该条云端记录，本机历史入口仍采用本机记录。云端分集 ID 与详情不一致时，使用有效云端集号定位，不预先导入本机历史。
- 首页使用按登录身份隔离的短期首屏缓存，预加载相邻作品，换剧时接续已完成或仍在进行的预加载；播放模型和视频索引按需读取，减少串行等待。首次冷缓存仍需联网，实际速度受网络、接口和设备解码性能影响。
- 找剧支持全部、真人剧、漫剧、AI 剧；按服务端返回的主题、设定、背景、推荐排序、受众、上新时间等分组组合筛选，漫剧还可返回作品状态。每组左右选择、组间上下移动，支持重置与收起筛选；进入海报列表保持展开状态，详情返回保留选中条件与位置。找剧分类页自动续页，返回键回顶并聚焦「找剧」，加载失败时提供重试。
- 关键词搜索覆盖全部剧集，提供遥控器三栏搜索：左侧 A–Z/0–9 键盘、删除/清空及中文/手机输入，中间联想词与最近历史，右侧剧集结果；方向键选字、确定输入。找剧组合筛选继续独立保留，可从「屏幕键盘」进入搜索、按返回回到筛选。
- 输入剧名、关键词或拼音时，停顿片刻显示服务端联想词；选中候选后搜索。联想失败仍可直接搜索，匹配范围取决于服务端，并非离线拼音检索。
- 综合、真人剧、漫剧、AI 剧热播榜，以及榜内题材筛选。榜单采用六列海报网格向下连续浏览，卡片显示原榜名次及可用热度，筛选后保留原榜名次。
- 搜索与分类结果接近底部时自动加载下一页，追加保留当前选中位置；搜索遇到临时网络或服务错误时自动重试一次，仍失败则显示错误类型并保留列表，支持手动重试与回到顶部。
- 剧集详情提供简介、选集列表、集数分组和跳转集数；相关作品支持前后季浏览、跳转及下一季预约。

### 追剧与账号

- 本机收藏、观看历史、断点续播及整剧已看标记；本机收藏可检查新增集数，长按作品管理记录。当前首页是首集试播流，续看和片单管理通过收藏、观看历史进入。
- 红果扫码登录，支持账户收藏读取与增删、账户观看历史及云端续播；收藏与历史均按本机／账户分设子页签。
- 账户预约区分已上线、待上线，并显示上线提示。

本机记录与账户云端记录分开保存。退出或切换账号会清除旧账号的云端列表，不删除本机历史。旧「稍后看」及备份恢复底层数据结构仍保留，但当前界面不提供对应入口，不将其列为可直接使用的功能。账号能力及同步边界见 [账号同步说明](docs/ACCOUNT_SYNC.md)。

### 播放与遥控器

- 遥控器方向键选剧、选集、快进快退，确认键播放／暂停；播放页按 ↓ 选集、↑ 打开更多，返回键先收起控制层，再退出播放。
- 清晰度、倍速、画面模式与自动连播可调整并记忆偏好。
- 定时停止支持按分钟、本集播完或再播完指定集数停止，保存观看位置。
- 播放失败提供有限次数自动重试、手动重试与清晰度切换；断网后等待联网恢复，保留续播位置。
- 首页与正式播放共用经平台注册的匿名播放设备身份，避免使用未注册的随机 ID；无需账号登录，注册失败会单独提示，成功后在本次应用进程内复用。
- 首页试播与正式播放遇到空播放信息时最多读取三次，瞬时连接故障重试一次；正式播放顺带读取后两集的播放信息，减少连续切集时重复请求。失败与重试期间保留具体错误原因，不保证平台持续异常时可恢复。
- 正式播放切到正在准备的下一集时接续原任务，避免取消后重复请求；下一集沿用当前播放会话，索引准备好即可入队，由播放器继续缓冲，不等待固定 2 MiB 下载。
- 按电视解码能力自动选流：超出盒子上限的清晰度（如竖屏高清）自动降档到可解的最高档位播放；盒子虚报能力导致播放失败时自动学习并降档重试，无需手动切换。
- 播放中监测音画偏移并自动重同步，缓解随播放时长累积（倍速下更快）的音画不同步。
- 应用内检查、下载及校验更新；同包名与原签名支持覆盖安装，新旧包名之间需单独安装。

### 评论与弹幕

- 详情页和正式播放页均可打开本集评论，支持连续加载、游标续读、去重、手动加载更多与失败重试。
- 常见表情使用随包图片显示，改善旧电视字库兼容；评论追加保留阅读位置，关闭面板恢复遥控焦点。
- 真实视频时间轴弹幕，暂停时冻结、快进快退后重新定位；支持开关、字号、速度、密度及本机设置记忆。

本集评论可连续读取，整剧剧评仍为官网公开节选。评论和弹幕均只读，未提供发送、回复或点赞操作；首页首集试播暂未接入评论与弹幕。实现与验收边界见 [评论与弹幕说明](kotlin-tv/SOCIAL.md)。

## Mac 客户端 hongguoMac

支持 **Apple Silicon（M 系列芯片）、macOS 13 及以上**。解压 ZIP，将 `hongguoMac.app` 拖入「应用程序」即可使用，自带运行环境，无需另外安装 Java。

[Mac 固定发布入口](https://gitcode.com/tsukiyo-zero/hongguoTV/releases/mac-stable) · [Mac 构建、更新与使用说明](desktop-mac/README.md)

- 首页推荐、漫剧和真人剧试播，支持切换作品、换批与下一部首集预加载。
- 搜索、分类找剧、排行榜、相关作品与前后季浏览。
- 红果扫码登录、账户收藏、观看历史、预约和正式观看进度同步；另有本机收藏与历史。
- 全屏播放、选集、清晰度、倍速、自动下一集及断点续播；全屏控制栏空闲后隐藏。
- 上下方向键切换试播作品，空格播放或暂停，左右方向键快退或快进 10 秒。
- 本集评论支持下滑连续加载与手动加载更多；整剧剧评提供官网公开节选。支持筛选、排序、复制及打开官方页面。

Mac 登录态保存在本机钥匙串，不随安装包分发。当前使用临时签名，尚未经过 Apple 公证；整剧剧评为官网节选，发送和回复尚未接入。另支持按视频时间同步的真实弹幕，可关闭及失败重试。

### Mac 更新与开发

Mac 与 TV **分别管理版本号和更新清单**。Mac 固定读取 GitCode 同仓库 `mac-stable` Release 中的 `mac-update.json`；每次发布上传新 ZIP 并替换该清单，保持标签不变，**不要将 Mac Release 设为 Latest／最新版**，最新版保留给 TV。Mac 目前下载并校验更新包后，需要手动解压替换应用。

已验证的 Mac 版本纳入 `main`。后续 Mac 开发继续在长期分支 **`feature-mac-client`** 进行，测试通过后按需通过 PR 合并到 `main`，不随每个 Mac 功能另开分支。TV 仍是主要维护版本，Mac 源码位于 `desktop-mac/`。

## Windows 客户端

支持 **Windows 10/11 x64**，以便携 ZIP 分发：解压后运行客户端程序，自带运行环境与播放库，无需安装 Java 或 VLC。

- **Flutter 重构版（验收中）**：`desktop-windows-flutter/`。界面参照「红果鉴」的浅色 / 深色主题，播放改用 media_kit（libmpv），新增弹幕画面叠加；[构建与使用说明](desktop-windows-flutter/README.md)。尚未发布正式下载包，可通过 GitHub Actions 构件或本地脚本构建。
- **Compose 版（当前正式分发的回退版本）**：`desktop-windows/`。使用 Compose Desktop 与 libVLC；[构建与使用说明](desktop-windows/README.md)。待 Flutter 版人工验收后再切换。

两版功能一致：首页推荐、搜索、找剧（漫剧 / 真人剧 / AI 剧与题材筛选）、热播榜、相关作品、详情选集、480P/720P/1080P、倍速、自动下一集、断点续播、本机收藏与观看记录；红果扫码登录后可查看账户历史、收藏、预约并同步播放进度。登录态用 Windows DPAPI 绑定当前用户加密保存在本机。

Windows 与 Mac 共用同一份本机 bridge 源码（`desktop-mac/backend`），UI 只通过带随机令牌的 127.0.0.1 接口取数据。Compose 版受 libVLC 独立视频表面限制无法叠加弹幕，Flutter 版已实现；两版均未接入自动更新。
